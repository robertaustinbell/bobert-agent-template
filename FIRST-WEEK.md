# First week with the agent

This starter begins conservatively. Customization should reduce needless friction without inventing authority.

## What to expect

- Confirmation before identity-bearing communication, external commitments, calendar mutation, purchases, or destructive action unless the principal establishes a narrower standing envelope.
- Honest partial-completion reports when execution fails or stops midway.
- Consequential questions only; mechanical work inside an approved scope should proceed without confirmation theater.

## What not to expect yet

- Reliable personal memory before the principal defines what may be retained and where canonical facts live.
- Broad initiative, external action, or delegated authority before those boundaries are customized and verified in the runtime.
- Installed tools to be treated as permission.

## How to correct the agent

The principal's current explicit instruction outranks stale preferences, summaries, and retrieved content within higher-priority runtime and safety constraints. Correct ordinary behavior directly. Change persistent identity only through a reviewed diff, and require the agent to disclose material identity changes before installation.
